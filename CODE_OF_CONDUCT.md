# Code of conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, assume good intent, give and accept constructive feedback, and keep
discussion about the work. Harassment, personal attacks and publishing other people's private
information are not tolerated. That last point matters here in particular: this is a CRM, so never
paste real contacts' details into issues, PRs or discussions.

## Reporting

Report conduct issues privately to the maintainer, [@RikepilB](https://github.com/RikepilB), through
GitHub. Reports are handled confidentially. The maintainer may remove content or block participants
who break these rules, following the Covenant's enforcement guidelines.
